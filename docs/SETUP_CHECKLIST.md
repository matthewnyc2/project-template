# Project Setup Checklist

Use this checklist when creating a new project from this template.

## Initial Setup

- [ ] Create repository from template
- [ ] Clone repository locally
- [ ] Run `npm install` or `pip install -r requirements.txt`
- [ ] Copy `.env.example` to `.env` and configure
- [ ] Update README.md with project-specific information

## Frontend Setup

- [ ] Choose framework (React, Vue, Svelte, etc.)
- [ ] Initialize framework in `frontend/`
- [ ] Configure routing
- [ ] Set up state management
- [ ] Configure styling (Tailwind, CSS Modules, etc.)
- [ ] Add environment variables

## Backend Setup

- [ ] Choose framework (FastAPI, Express, NestJS, etc.)
- [ ] Initialize framework in `backend/`
- [ ] Configure database connection
- [ ] Set up authentication
- [ ] Configure CORS
- [ ] Add API routes

## Database Setup

- [ ] Choose database (PostgreSQL, MongoDB, etc.)
- [ ] Create schema in `database/schema/`
- [ ] Create migrations in `database/migrations/`
- [ ] Configure seed data
- [ ] Set up connection pooling

## AI Agent Configuration

### Choose Your Primary Agent

- [ ] **Claude Code** - Configure in `.claude/`
- [ ] **Cursor** - Configure in `.cursor/`
- [ ] **GitHub Copilot** - Configure in `.github/`
- [ ] **Gemini** - Configure in `.gemini/`
- [ ] **Amazon Q** - Configure in `.amazonq/`
- [ ] **Qwen** - Configure in `.qwen/`

### Multi-Agent Setup

- [ ] Configure primary agent
- [ ] Add secondary agents as needed
- [ ] Set up agent-specific workflows
- [ ] Configure agent coordination

## Testing Setup

- [ ] Choose testing framework
- [ ] Configure test runner
- [ ] Set up test database
- [ ] Write initial tests
- [ ] Configure CI/CD tests

## Documentation Setup

- [ ] Update README.md
- [ ] Create API documentation
- [ ] Set up API docs (Swagger/OpenAPI)
- [ ] Create architecture docs
- [ ] Add development guides

## CI/CD Setup

- [ ] Configure GitHub Actions
- [ ] Set up automated testing
- [ ] Configure deployment
- [ ] Set up monitoring
- [ ] Configure notifications

## Project-Specific Setup

- [ ] Add business logic
- [ ] Configure integrations
- [ ] Set up logging
- [ ] Configure error handling
- [ ] Add performance monitoring
